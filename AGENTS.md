# AGENTS.md

## Objectif du projet

Ce projet est un site web de démonstration développé avec l'aide d'un agent ChatGPT.

Le site est publié avec GitHub Pages.

## Technologies

Le projet utilise uniquement :
- HTML5
- CSS3
- JavaScript

Ne pas ajouter de framework ou de dépendance externe sans autorisation.

## Structure du projet

Les principaux fichiers sont :

- `index.html` : page principale
- `style.css` : styles du site
- `script.js` : comportement JavaScript
- `README.md` : documentation du projet
- `REQUESTS.md` : demandes d'évolution du projet
- `AGENTS.md` : instructions permanentes pour l'agent

## Règles de développement

Avant toute modification :

1. Lire `AGENTS.md`.
2. Lire `REQUESTS.md`.
3. Examiner le code existant avant de le modifier.

Lors du développement :

- conserver une structure simple et lisible ;
- éviter le code inutile ;
- utiliser du HTML sémantique ;
- séparer HTML, CSS et JavaScript ;
- conserver la compatibilité avec GitHub Pages ;
- ne pas introduire de backend ;
- ne pas introduire de dépendances externes sans autorisation.

## Interface utilisateur

Le site doit avoir une apparence :
- moderne ;
- simple ;
- professionnelle ;
- responsive pour ordinateur et smartphone.

## Tests

Après chaque modification :

1. vérifier que la page se charge correctement ;
2. vérifier qu'il n'y a pas d'erreur JavaScript ;
3. tester les fonctionnalités modifiées ;
4. vérifier que les modifications n'ont pas cassé les fonctionnalités existantes.

Ne pas considérer une demande comme terminée si les tests échouent.

## Gestion des demandes

Les demandes d'évolution sont enregistrées dans `REQUESTS.md`.

Lorsqu'une demande est réalisée :

1. implémenter la fonctionnalité ;
2. la tester ;
3. mettre à jour `REQUESTS.md` ;
4. indiquer clairement que la demande est terminée.

Ne pas supprimer les anciennes demandes de `REQUESTS.md`.

## Git

Effectuer des commits clairs et ciblés.

Exemples :

`feat: add dark mode`

`fix: correct click counter`

`style: improve mobile layout`

Éviter de regrouper plusieurs modifications sans rapport dans le même commit.

## Déploiement

Le site est publié avec GitHub Pages.

Toute modification doit rester compatible avec ce mode de déploiement.

Après une modification destinée à la production, vérifier que le site publié fonctionne correctement.

## Autonomie de l'agent

L'agent peut de manière autonome :

- créer et modifier les fichiers du projet ;
- corriger des bugs ;
- améliorer le code ;
- exécuter les tests ;
- mettre à jour `REQUESTS.md`.

L'agent doit demander confirmation avant :

- de supprimer une fonctionnalité importante ;
- de changer de technologie ;
- d'ajouter une dépendance externe ;
- de modifier l'architecture générale du projet ;
- d'effectuer une action irréversible.
